Entry for the [make.fun bounty "One Sentence for a Traveler from 1800"](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb).

## What it does

`main.py` writes one sentence (186 characters) to `/output/entry.txt`. The
sentence explains the modern internet to a time traveler who has just stepped
out of the year 1800, using only words and pictures a person from that year
already knows — a post office, a letter, ink drying, shelves of books — and
no word coined after their time.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic, no network, no input. Requires Python 3.
